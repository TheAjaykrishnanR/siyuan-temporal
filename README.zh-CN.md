# SiYuan Temporal — 思源全能时间管理中枢

**SiYuan Temporal** 是基于 **React**、**Tailwind CSS** 与 **shadcn/ui** (Radix UI) 构建的思源笔记全能时间插件，提供专属标签页以及后台真实音效提醒引擎。

## 核心功能

1. **时钟套件（闹钟、计时器、秒表、世界时钟）**
   - **真音效闹钟**：内置 6 种 Web Audio API 合成多音色铃声（马林巴琴、经典石英钟、颂钵、竖琴琶音、合成器、紧急脉冲）及自定义音频链接，支持贪睡延迟。
   - **多任务倒计时器**：环形进度条、番茄钟预设与自定义时长。
   - **高精度秒表**：毫秒级计圈、最快/最慢圈高亮，一键复制为 Markdown 表格。
   - **世界时钟**：多时区实时对照与昼夜指示。
2. **自定义提醒（支持任意年、月、日、时间）**
   - 配备月份/年份快速跳转的 shadcn 日历选择器、重复周期（单次/每天/每周/每月/每年）、优先级、分类及思源块跳转链接。
3. **日历与 Google Calendar 深度集成**
   - 支持 **月视图**、**周视图**、**日程列表（Agenda）**。
   - 支持 **Google 日历 iCal (`.ics`) 私密链接**（通过思源内核代理免除跨域限制）、**OAuth 2.0 访问令牌**（支持双向创建日程）及 **API Key**。
